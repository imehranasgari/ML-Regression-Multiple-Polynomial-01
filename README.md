

# Multiple and Polynomial Regression

## Problem Statement and Goal of Project
This notebook investigates **multiple linear regression** and **polynomial regression** techniques for modeling and predicting relationships between variables in a dataset. The goal is to understand, apply, and compare these regression approaches in practice, analyze results, and reflect on common issues and learning points.


## Solution Approach

- The notebook starts with data loading and inspection.
- Data cleaning and preprocessing steps are applied as needed.
- Both **Multiple Linear Regression** and **Polynomial Regression** models are implemented using scikit-learn.
- The workflow includes data splitting, model training, prediction, and performance evaluation.
- Sample outputs, errors, and analysis are provided for transparency and learning.

## Technologies & Libraries

- **Python** (Jupyter Notebook)
- **pandas**: For data manipulation and analysis
- **numpy**: For numerical operations
- **scikit-learn (sklearn)**: For regression models, data preprocessing, and evaluation metrics
- **matplotlib / seaborn**: For data visualization (where relevant)
